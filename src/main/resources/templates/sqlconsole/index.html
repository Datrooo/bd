SQL-консоль

Изолированный технический раздел только для `SUPERADMIN`. Консоль выполняет только read-only `SELECT`/`WITH` запросы к прикладной PostgreSQL-схеме через отдельного ограниченного DB-пользователя.

SELECT/WITH only
Выполнение запроса

SQL editor

Разрешен один statement. Модифицирующие, DDL и административные команды отклоняются до выполнения.

Ошибка.
Очистить
Политика безопасности

Ограничения консоли

  • Только `SUPERADMIN`.
  • Только один `SELECT` или `WITH` statement.
  • Только прикладные таблицы и безопасные SQL-функции.
  • Системные namespace PostgreSQL недоступны.
  • Лимит результата: 200 строк.
  • Таймаут выполнения: 10 секунд.
  • Соединение открывается в `readOnly` режиме под отдельным DB-user.
  • Попытки выполнить запрещенные команды логируются.
Пример
SELECT id, username, is_active
FROM app_user
ORDER BY id;
